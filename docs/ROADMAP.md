# 拳击养成游戏长期计划

> 制定：2026-10-24 | 原则：系统先于美术，每个阶段结束都有可玩版本，按兴趣和空闲推进，无硬性 deadline
>
> **迭代方式（2026-10-24 定）**：两轮走——第一轮按 Phase 1→5 顺序把整套系统先跑通；每个 Phase 结尾总结给用户，用户给建议后再继续；2~3 轮后助手已摸清用户偏好，转自主 loop；第一轮完成后做一次整体评估，总结问题清单；第二轮按同样顺序逐项回炉更新迭代；完成度足够后进 Phase 6+。

## 已完成

- **Phase 1：核心循环原型**——每日 AP 分配、13 种训练（5 点训练计划）、打工/外出/休息、心态系统、状态界面＋背包、三模式战斗（手动/自动观看/模拟跳过）、触屏＋键盘双输入、行动确认框
- **Phase 2：排名 / 伤病 / 商店**——国内排名 50 名起步±5 匹配升降、奖金与排名挂钩；伤病 debuff 分档＋医院治疗；商店扩充 6 件装备＋拳套图鉴
- **Phase 3：分阶段目标 / 粉丝 / 赞助**——6 生涯阶段＋称号、粉丝增减与奖金加成、4 档赞助签约与周薪
- **设计资产**——主角立绘 v8 定稿（粉色高马尾）、局内动画规划（五之二）、《Love * Upper!》战斗机制调研、发型参考 9 种

## Phase 4：战斗深化（2026-10-24 已落地：组合拳、反击窗口、破防克制、AI 三风格、击倒读秒、回合间休整）

目标：让战斗从"贴身出拳循环"变成有决策的攻防。

- 组合拳：连续命中连击计数＋伤害加成
- 反击窗口：闪避成功后 1 秒内出拳伤害加成
- 破防克制：高位格挡防不住击腹，击腹破防接直拳成标准连招
- AI 风格：力量型 / 速度型 / 防守反击型，对手打法各不同
- 击倒/读秒：被重击倒地→读秒→可起身再战，不只有 KO 一种结局
- 回合间：体力小幅恢复＋伤势显示
- 完成标准：手动打一场能明显感觉到"打对了"和"打错了"的区别

## Phase 5：装备深层系统

- 双层结构落地：版型（守护/斗牛/经典）× 材质（外皮＋内衬）× 盎司（8~16oz）× 固定方式（系带/魔术贴）
- 制作系统：拆解淘汰装备→皮料/内衬材料→按配方打造新装备
- 拳套图鉴成就：集齐奖励
- 完成标准：装备不再是几件固定商品，而是一套可搭配、可打造的系统

## Phase 6：捏人 / 换装 / 换发型

- 捏人系统：脸型、体型等基础选项
- 换发型：9 种发型（高马尾、公主切、大波浪、半扎发、超短发、麻花辫、黑长直、丸子头、水波纹）立绘变体，状态界面切换
- 服装换装：战袍/训练服外观切换
- 完成标准：主角外观可自定义，且不破坏现有立绘风格

## Phase 7：剧情 / 恋爱线

- 序章：街机拳机→被发掘→进拳馆（参考《マグナムリリィ》素人开局）
- 分阶段剧情事件：随生涯阶段解锁
- 恋爱线（可选）：队友/对手等角色好感事件
- 完成标准：生涯有了故事线，但不强制、不干扰核心循环

## Phase 8：Godot 正式版迁移

- 前置条件：有 PC（目前只有安卓手机，网页原型先行）
- 从网页原型迁移到 Godot 4，系统设计原样搬运
- 骨骼动画＋AnimationTree 状态机（见设计文档五之二）
- 正式美术资源替换占位图
- 完成标准：Godot 版玩法与原型一致，表现升级

## Phase 9：打磨与发布

- 数值平衡总调（训练收益、战斗难度、经济曲线）
- 音效/音乐完整化
- 成就系统
- 发布准备：itch.io / Steam 页面、试玩反馈收集

# 发布清单（P4 用，提前看）

## 版本
- [ ] 版本号：`project.godot` 的 `config/version`，规则 `主.次.补丁`（1.0.0）
- [ ] `CHANGELOG.md` 写好本版内容
- [ ] git 打标签 `v1.0.0`

## 内容合规
- [ ] 游戏里没有占位名 / 占位图 / 内部 id
- [ ] 所有素材在 `CREDITS` 里有来源和许可证；没有来源不明的文件（BGM 已确认）
- [ ] CC BY 素材的署名出现在游戏内致谢页和发布页
- [ ] 字体许可证文件随包附带（例：思源黑体 OFL）
- [ ] 不含任何参考游戏（Love Upper、Bloom Blow）的资源
- [ ] AI 生成美术：在发布页说明生成方式（如实披露）

## 构建
- [ ] Godot 导出模板与编辑器版本一致（4.7.2）
- [ ] Windows 导出：图标、程序名、版本信息
- [ ] 导出包体检查：没有把 `scripts/dev/`、`tools/`、研究文件打进去
- [ ] zip（免安装）；可选：安装程序
- [ ] 干净电脑实测（`TESTING.md` 发布前回归）

## 设置默认值
- [ ] 默认窗口化 1280×800 或跟随显示器；全屏可切
- [ ] 默认音量适中（BGM −14dB）
- [ ] 存档位置：`user://`（Windows 下 `%APPDATA%\Godot\app_userdata\<项目名>`），在说明里写明

## 发布页（DLsite：先体验版，后正式版）
- [ ] 账号与页面由用户本人注册 / 创建
- [ ] 标题、一句话介绍、详细介绍（玩法、操作、通关时长）
- [ ] 5~8 张截图 + 1 个 30 秒视频或 GIF
- [ ] 标签：boxing、anime、sports、simulation、management
- [ ] 体验版免费、正式版定价；所有素材授权允许商用（CREDITS 逐条核对）
- [ ] DLsite 社团注册、作品分类 / 年龄分级、作品页文案（日文为主）
- [ ] 系统要求、操作说明、已知问题
- [ ] 反馈渠道（DLsite 评论 / 问卷链接）

## 发布后
- [ ] 一周内收集反馈，整理成 `playtests/` 报告
- [ ] 补丁按 `WORKFLOW.md` 流程走，存档向后兼容

## 建议的 Phase 3 范围（只做三件）

### 1. 分阶段目标：把 §六的长线切成看得见的里程碑
- 沿用现有链：地区新人赛 → 国内排名赛 → 洲际头衔战 → 世界金腰带 → 统一战 → 卫冕。
- Phase 3 只落地“国内段”的目标线，与 Phase 2 已有的国内 1–50 名排名直接挂钩，例如：
  - 打进前 30 / 前 10 / 前 5 / 获得国内头衔挑战资格（具体名次阈值由你定，上面只是示例）。
- 每个目标达成时给明确奖励（奖金、装备或头衔赛资格三选一，具体见“待你定的三点”）。
- 洲际及之后的世界线、统一战、卫冕留在后续阶段，不进 Phase 3。

### 2. 粉丝系统：赢比赛 → 涨粉丝，粉丝是经营线的货币
- 粉丝数显示在状态页；胜场涨粉，涨幅随对手排名提高、KO/精彩胜利加成；输了小幅掉粉（不设惩罚性暴跌）。
- 粉丝里程碑解锁下一项：赞助合同档位、更高出场费（与 Phase 2“奖金与排名挂钩”并行，不互相覆盖）。
- 不做粉丝互动、社交剧情，那是恋爱/剧情线（Phase 4）的事。

### 3. 赞助系统：三档合同，签了就按周给钱
- 三档示例：本地小店 → 运动品牌 → 全国品牌，门槛分别是粉丝数与国内排名双条件。
- 签约后每周固定赞助收入，直接进钱包，可用于 Phase 2 已有的商店买装备、医院治伤病——这样 Phase 3 的钱立刻有地方花，循环闭合。
- 合同期满可续约/升级；Phase 3 先不做“违约罚金、赞助商强制比赛”这类经营压力，后续阶段再加。

## 明确不做（留在 Phase 4 或更后）
- 捏人系统、恋爱/剧情线、美术升级（文档 §九 Phase 4 已定）。
- 多组织统一战、卫冕期的强制卫冕期限（现实调研里提过，适合以后做剧情冲突，不进本期）。
- 粉丝剧情事件、赞助商专属任务。

## 验收标准（沿用 Phase 2 的做法）
- 模拟打若干周：粉丝随胜负合理涨跌，不出现一夜爆红或怎么赢都不涨；
- 赞助三档按门槛正常解锁，签约后每周到账金额与说明一致；
- 老存档自动补粉丝/赞助字段，不丢 Phase 2 的排名、装备、伤病数据。

## 待你定的三点（不用现在回）
1. 目标奖励给什么：奖金为主，还是给装备/头衔赛资格？
2. 粉丝要不要衰减：长期不比赛掉粉，还是只涨不跌？
3. 赞助要不要带义务：只给钱，还是附带“每月至少赢一场”之类的简单条件？

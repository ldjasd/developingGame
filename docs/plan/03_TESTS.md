# 03 · 实现后的测试（验收标准）

> 版本：v1（2026-11-10）。通用门：每批 `npm run build && npm test` 全绿（基线 249，只许增不许减、既有断言不许改口径放行）；SW 版本号 +1；老档兼容探针（Day 35 档）加载与关键字段不回退。
> 证据纪律：结论必须有脚本日志或截图存档；子代理汇报的关键数字由主助手抽查原始日志后才写入 `04_CHANGELOG.md`。数值结论看分布：同一脚本至少 2 个种子/2 次跑，方向一致才算成立（研 6）。

## G0 工具链
- ko-impl-verify `--fast` 能在可接受时间内跑完且**逐环境出数**（不再零输出超时）。
- 构建日志体积与实际文件字节一致；batchB_lab 默认口径跑出的矩阵与 persona 基线一致。

## G1 生涯难度（核心验收，全过才算完成）
用复测同款轨迹脚本（`research/retest_logs_20261110/retest_career_traj.mjs` 同法）跑投入型生涯 12 周 ×2 种子：
- 平均回合 **≥1.8**（现 1.08）；R1 终结率 **≤40%**（现 91.7%）。
- 12 周战绩不全胜碾压：胜率落在 **55%~85%** 区间（投入型打法应仍占优，但要有输有赢）。
- 登顶周数 **≥W13**（现 W12，且过程名次轨迹无长期锁死——排名跑步机不许回退：五成胜率探针 batchA_fifty 仍缓爬）。
- 中盘点数终局回流：实验室中盘对局点数终局占比 **≥10%**。
- 不许回退项：练习赛打满 R3 点数；前三周平均回合 ≥2.1、R1 终结 ≤25%；t6 环境胜率与回合数在 KO 批基线噪声内（59%±8pp / 1.93±0.25）。

## G2 纸偶扩围
- 逐人四态截图（待机/直拳/受击/击倒）＋身份三联图（纸偶 vs 本人立绘 vs 原静态图）由主助手逐张目检：无空洞/断面/翻腕、脸与发型服装一致。
- 母版覆盖率统计落字（目标 ≥70% 槽位可由母版/换色覆盖；低于此值先修规格再继续）。
- 性能：CPU 4× 节流下战斗页 ≥50 FPS；冒烟全绿；回退开关逐人实测（关 rig 回到静态图不报错）。
- 包体增量：每人部件 ≤120KB 量级，8 人合计在 itch 包可接受范围内并记录。

## G3 模拟与指令
- ko-sim-fit 复测：pow/spd/tec 三构筑引擎 vs 模拟胜率残差均 **≤10pp**（n≥150）。
- cmdab 双口径（persona/asis）复跑：smart−off ≥+10pp 保持；spam−smart 落在 **±5pp** 内（现 +17/+21pp）。

## G4 存档安全
- 新增冒烟断言全过：旧版档迁移后关键字段与迁移前一致；损坏档（截断 JSON）加载时锁定不回写、原数据保留；版本过高档同理；导出→清空→导入往返后存档深等价。
- 真机路径抽查：设置屏导出/导入各走一遍无报错。

## G5 教程
- 开局实测数据落字：新档到首场正式赛的点击数与教学弹窗数（对比重构前基线）、每屏新概念数 ≤3 的盘点表。
- 练习赛与首场正式赛的新手胜率/回合数不回退（同 G1 不许回退项）。

## G6 平台小件
- Playwright 抽查：全屏按钮可进可退、Esc 能关最上层弹窗且不误关比赛；标题 BGM 与 daily 可分辨、切换无爆音；TKO 日志新文案出现且不再提「死战设置」（全仓 grep 该词归零或仅存注释）。
- 弱网口径（Fast 3G＋CPU 4×）标题可交互 ≤5s 不回退（批次 E 基线 4.6s）。

## G7 人格与 TKO
- foeai 采样：调整日志场均 **≥0.4**（现 0.15）；R1 战术=人格 base 仍 100%。
- TKO 实验（若合入）：势均力敌样本（t6/spd）出现 TKO 例且占比 <10%；悬殊局 TKO 占比不高于现生涯基线（2/12）量级；单回合 3 击倒规则与读秒流程冒烟不断言回退。

## G8 发布与包体
- release-check 脚本对当前 itch 包全项通过；故意构造一个坏包（改大小写/挪 index）能被检出。
- 双份图若合并：三处截图（排名/名鉴/战斗）合并前后对比无可见差异，dist 总量下降数值落字。

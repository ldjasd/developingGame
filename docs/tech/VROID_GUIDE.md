# VRoid 建模指引（主角 + 林小葵）

> 用途：按现有立绘捏出两个 3D 战斗模型，替换试点里的样例模型。做完把 .vrm 文件放进仓库（位置见 §5），告诉 Claude 即可，导入、拳套、动作、镜头由 Claude 接。
> 参照立绘：主角 `godot/assets/ui/hub_me.webp`；林小葵 `godot/assets/fighters/portraits/opp_rookie.webp`。
> 预计时间：第一次每人 1~2 小时，熟练后 30~60 分钟。

## 0. 安装
- VRoid Studio：官网 https://vroid.com/studio （免费，Windows 版；Steam 上也有）。
- 打开后选「新建」→ 女性模板。

## 1. 共同原则
- **身材**：精瘦匀称、淡淡马甲线，不要夸张肌肉（2026-11-02 用户定稿）。体型滑块里把「身高」放中间偏低（约 155~160cm）、肩宽略窄、腰细。
- **不要做拳套**：拳套由游戏里另外挂模型（可换颜色），手保持默认张开的手即可。
- **服装是运动服**：短款上衣 / 背心 + 百褶短裙 + 运动鞋，和立绘一致。裙摆不要太长太宽，否则出拳时手臂会穿过裙子。
- **头发不要太长太散**：长发会在出拳时穿过手臂。主角的马尾可以长，但发束别太多。
- **配色以立绘为准**：拿取色器从立绘图里吸颜色（数值见下表）。

## 4. 导出
1. 右上角「拍照 / 导出」→「导出 VRM」。
2. 版本选 **VRM 1.0**（0.0 也能用）。
3. 减面：多边形减少设为「中」左右；材质合并（贴图集）开启，贴图尺寸 2048。
4. 元信息（许可）：作者填你自己的昵称（不要填真名）；「允许他人使用」可设为「仅作者」；其余默认。
5. 文件名：主角 `me.vrm`、林小葵 `rookie.vrm`。

## 5. 放到哪里
- `godot/assets/characters3d/me.vrm`、`godot/assets/characters3d/rookie.vrm`
- 同时保存 VRoid 工程文件（.vroid）到仓库外备份，以后改发型 / 换装还要用。

## 6. Claude 接手后会做的
- 导入，换掉试点里的样例模型；挂拳套（主角紫、林小葵绿）；
- 按 `design/battle.md` 的节拍检查出拳、闪避、受击、倒地动作有没有穿模；
- 录一版背后视角视频给你看，确认「像不像立绘里的人」。

## 常见问题
- **脸不像**：VRoid 的脸偏「标准 VRoid 脸」，重点调眼睛大小 / 间距 / 下垂程度和刘海形状，最影响「像不像」。
- **颜色不一致**：游戏里用卡通着色，颜色会比编辑器里暗一点，可以整体调亮 5~10%。
- **文件太大**：超过 30MB 时，把减面调高一档、贴图降到 1024。

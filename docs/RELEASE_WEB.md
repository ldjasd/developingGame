# Web 版发布目标（2026-11-02 用户定）

用户明确：Web 版的目标是**能往游戏网站正式发布**，不是初级试玩版。这里的 artifact 只是内部预览通道，不是最终交付形态。Phase 8 Godot 仍是长期 PC 方向，两条线并行：Web 版按可发布产品标准打磨。

## 首选发布渠道

- **itch.io**（HTML5 游戏：上传 zip、勾选在浏览器中运行；免费、门槛最低，先行目标）
- 后续可考虑：CrazyGames / Poki（需审核与 SDK 接入，另行评估）、Steam（等 Godot 版）

## PWA 应用化（2026-11-02）

用户定调「不要像 HTML，要像应用程序」，Web 版已做成可安装的 PWA（仍是同一份包，itch 版同步生效）：

- **构成**：`manifest.webmanifest`（名称《心跳在左，拳头在右》、short_name「心跳在左」、standalone 全屏、竖屏、主题色/启动背景深紫 `#4a2a7a` 与游戏代表色一致、`start_url`/`scope` 全用相对路径，itch 子目录托管与独立域名都成立）＋ `sw.js`（根目录）＋ 图标组 `assets/icons/`（192/512/maskable 512/apple-touch 180/favicon，2026-11-02 再次按用户反馈重做：主体改为一对与封面同款的拳击手套——从定版封面底图抠出主角右手那只深紫白星拳套（粉色腕带＋白色缠手带衔接）并镜像成对、旋转成立姿，底为左粉右紫代表色对分，一条白色心电波形线横贯下部、右侧收束成金色星星；48px 缩略下双拳套轮廓仍一眼可辨。此前两版均已被取代：compact 星星款因顶部带分指凹凸被否、图鉴池 pillow 系列因质感太软被否）。
- **安装方法（安卓）**：用 Chrome 打开游戏页面（itch 上点开游戏页或独立托管链接）→ 浏览器菜单选「添加到主屏幕」（部分机型/版本会直接弹出「安装应用」提示，点安装即可）→ 桌面出现「心跳在左」图标。安装后点图标**全屏启动、无浏览器地址栏与边框**，和原生应用一样的打开方式；iOS Safari 走「分享 → 添加到主屏幕」同样可用。
- **离线可玩**：Service Worker 首次联网打开时缓存核心文件，游玩过程中把访问过的图片等静态资源逐个写入运行时缓存；之后断网（含飞行模式）点图标即可打开并继续玩（存档本来就在本机 localStorage，不受影响）。
- **更新机制**：SW 导航请求走网络优先（联网时自动拿最新版，不会卡在旧缓存）；版本号常量 `SW_VERSION`（现 `boxing-pwa-v5`，封面同款拳套图标版由 v3 升至 v4、图标修整版再升至 v5）写在 sw.js 顶部，发布新版时 +1，新 SW 接管时自动清除全部旧缓存。
- **图标与封面修整（2026-11-02，用户反馈）**：图标按用户要求把一对封面同款拳套左右对调（模板匹配实测旧版为左镜像/右原图，新版改为左原图/右镜像），并从定版封面底图重新抠图补齐腕部——粉色腕带与白色缠手带衔接完整、底边平直收尾，512 原图与 48px 缩略均目视无缺口；五件图标整套重出，SW 升至 `boxing-pwa-v5`。itch 封面同步做排字艺术化：标题整体上移至画面上方、置于半透明深紫斜切缎带衬底上与人物脱开（不压脸、不压右拳），字做渐变填充＋深紫/金/白三层描边＋轻斜切与投影，缎带右端以金绳垂挂一只同款小拳套挂饰，另点缀小金星与一段心电线穿过标题区，副标「从无名到世界冠军」移至左下；210px 缩略下八字仍可辨认。
- **环境说明（如实）**：内部 artifact 预览通道下，预览域名/路径策略可能限制 SW 注册与安装提示——注册代码已做静默降级，预览里装不上不影响游玩、也不是包的缺陷；**PWA 安装与离线能力以 zip 包托管形态（itch 或任意 https 静态托管）为准**，上架后建议用户在 itch 页面实测一遍安装流程。

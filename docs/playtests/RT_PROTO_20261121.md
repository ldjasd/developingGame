## 怎么玩
用 Godot 4.7.2 打开 `godot/project.godot`，在文件系统里双击 `scenes/dev/rt_proto.tscn`，按 F6（运行当前场景）。

| 操作 | 键 |
|---|---|
| 刺拳 / 直拳 | J / K |
| 上勾 / 击腹 / 摆拳 | 按住 W / S / A 或 D，再按 J 或 K |
| 格挡 | 按住空格（同时按住 S = 低格挡，专防击腹） |
| 闪避 | Shift + A / D 左右闪，Shift + S 下潜 |
| 切镜头 | C（背后 / 斜后方） |
| 再来一局 / 退出 | Enter / Esc |

小提示：对手出拳前拳套会**发黄光**（预兆）。直拳和刺拳用左右闪躲，摆拳用下潜躲；躲开后 1 秒内反击伤害 +40%。

## 现在有的
- 3 回合 × 60 秒；回合间暂停 3 秒，有开场铃 / 终场铃。
- 双方 HP（粉）、体力（蓝）、重创（橙）条；回合钟。
- 出拳、格挡（高 / 低）、三向闪避、受击后仰 / 弯腰、重击推镜 + 顿帧、真实音效。
- 「反击！」「N 连击」「闪开了！」「击腹破防！」提示；被打中时屏幕泛红。
- 击倒：单膝跪地 → 读秒数字 → 站起来；KO 时读到 10 → 「K.O.」→ 结果。读秒时站着的一方让到一边，倒地的人始终看得见。

## 自动跑的观察（AI 对 AI）
- 势均力敌（属性 30 vs 30）一场打满 3 回合判定；属性 40 vs 26 一场：第 2 回合击倒读到 5 起身，第 3 回合再次击倒读到 10 KO。
- 画面上能分辨：对手预兆、下潜（主角虚影下沉）、对手出拳打到镜头前、击倒跪地。

## 已知问题 / 下一步
1. **需要你上手打一局**，按 `process/TESTING.md` 第 4 层的问卷打分：看得出对手出什么拳吗？按键有没有延迟？闪避反击爽不爽？
2. 样例模型穿裙装、和我们的角色不像 → 等 VRoid 模型（`tech/VROID_GUIDE.md`）。
3. 拳套是球体占位 → 要做拳套模型。
4. 头发不摆动（未启用原生物理库）。
5. 没有回合间指导面板、赛前 VS、必杀；没有接进生涯（还是独立场景）。
6. 动作是程序生成，略僵硬；正式版考虑加动作捕捉素材（Mixamo）或手调关键帧。

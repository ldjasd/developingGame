# 实时战斗规则内核 BattleCore：首次标定（2026-11-21）

> 代码：`godot/scripts/battle/battle_core.gd`；探针：`godot/scripts/dev/rt_probe.gd`；冒烟新增 6 项断言（`dev/smoke_test.gd`）。
> 复跑：`godot --headless --path godot --script res://scripts/dev/rt_probe.gd -- --n=167 [--hp=3.0] [--decay=0.55] [--rate=1.0]`

## 做了什么
- 规则层逐项沿用回合制引擎（伤害公式、连击、减伤封顶 70%、击腹穿透 70%、重创 K=40 与 25/50/75 击倒、方案 B 读秒起身、同回合 3 倒 TKO、点数判定）。
- 新增实时部分：出拳前摇 / 停留 / 收招（Love Upper 帧数据）、AI 预兆 0.4 秒、受击打断蓄拳、受击硬直分档、方向闪避（摆拳克侧闪、上勾克下潜）+ 1 秒反击窗口（对应拳 +40% / 其他 +30%）、高 / 低格挡与破防、体力回复、空挥加收招。
- AI 大脑：看到对方出拳按防守能力决定格挡 / 闪避（方向可能闪错）、反击窗口立刻还击、按风格权重和出拳速度决定进攻节奏、35% 概率连打。
- 无画面可跑：1000 场约 2.5 分钟。

## 发现的问题（留给后续）
1. **重创满格 KO 实际为 0%**：HP 池放大后单拳重创增益变小，重创只会触发 25/50/75 击倒，打不满 100。是否保留「重创满格 KO」这条路，留到手动试玩后再看（可动重创衰减或 K 的标定）。
2. **+6 属性胜率 93% 偏陡**（回合制版是 84%）：训练的价值很大，但开局卡墙会更明显。和 `design/career.md` §2.2 难度梯度一起调。
3. 这是 **AI 对 AI**（自动观看同构）。手动模式下玩家能读预兆、闪避反击，胜率会更高；要等手动版做好后用真人和「随机按键机器人」各测一轮。
4. 还没有距离概念（背后视角下先假设一直在拳距内）。是否加「前后距离」待手动试玩决定。

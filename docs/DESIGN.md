# 拳击养成游戏 · 设计文档（v0.2）

> 更新：2026-10-24 ｜ 状态：概念细化中

## 一、核心概念

- **类型**：拳击题材 × 养成经营模拟（PC）
- **主角**：二次元画风美少女拳击手（未来支持捏人自创角色）
- **主线**：暂无固定主线剧情，采用**分阶段目标制**（新人赛 → 国内 → 洲际 → 世界）
- **生涯**：不设时长上限，可长期游玩
- **剧情/恋爱线**：可选；主角可设定为恋爱对象（男朋友 / 女朋友），不影响主循环

## 二、平台与技术

- **平台**：PC（Windows 优先）
- **引擎推荐**：Godot 4（免费开源、2D 强、PC 导出方便，单人开发友好）
- **原型策略**：先做可玩原型验证核心循环，美术用占位资源

## 三、美术风格

- **参考方向**：米哈游《崩坏：星穹铁道》《绝区零》式二次元渲染 ＋ 日系风格混合
- **现实备注（重要）**：米哈游级美术是数百人团队的产物，单人无法复刻同等质量。务实路径：
  1. 原型期：几何体/火柴人占位，只验证玩法
  2. 2D 方案：AI 生成立绘 ＋ 2D 骨骼/剪影战斗表现，二次元观感足够
  3. 3D 方案（远期）：VRM 模型 ＋ 风格化渲染
- **结论**：先 2D 验证，再决定是否上 3D
- **发型参考**（2026-10-24 用户提供视频，同角色同服装只换发型对比）：高马尾（主角现有）、公主切、大波浪、半扎发、超短发、麻花辫、黑长直、丸子头、水波纹——全部 9 种均可作为主角换发型选项，游戏不必拘泥真实；也适合捏人/其他角色设计参考

## 四、核心循环

每日行动点（AP，如每天 6 点）→ 分配给训练 / 打工 / 休息 / 比赛 →
属性、 金钱、状态变化 → 报名比赛 → 获胜提升排名与名声 →
解锁更高级赛事与更强对手 → 回到训练

## 四之一、外出系统与心态系统（2026-10-24 新增）

### 外出（2AP/次，子菜单二选一）
- **体育用品店**（简化版装备商店，Phase 1 先上基础款）：
  - 新手拳套：力量+1，¥500
  - 标准拳套：力量+2，精准度+1，¥1500
  - 专业拳套：力量+3，精准度+1，出拳速度+1，¥4000
  - 基础护齿：减伤+5%，¥800
  - 轻便战靴：步伐速度+1，¥1200
  - 规则：拳套/护齿/战靴各限装备一件，买新的替换旧的
- **散心**（三选一：看电影/逛街/吃美食，效果相同）：心态+20，体力+10，花费¥300

### 心态系统（新属性）
- **心态值** 0~100，初始 60；状态栏显示数值+状态名
- **五档状态**：80+ 高昂 / 60~79 良好 / 40~59 平稳 / 20~39 紧张 / 0~19 疲劳
- **影响来源**：散心+20，购物+10，获胜+15，战败-10，被KO-25，大赛前夜-10，体力枯竭时训练-10，休息+5，冥想+10
- **效果框架**（具体数值后续调，先搭框架）：
  - 高昂：训练效率+10%
  - 疲劳：训练效率-15%，比赛体力消耗+10%
  - 紧张：比赛前两回合全属性小幅下降
  - 良好/平稳：无修正

## 五、战斗系统：三模式（2026-10-24 改版：主角=玩家自己）

### 核心改版
- **主角即玩家自己**，不再需要教练 NPC（原"教练视角"改为"你就是拳手"）
- 恋爱线也因此更自然：主角（玩家）与其他角色发展关系

### 三种战斗模式
1. **手动操作**（核心体验，用于重要比赛）
   - 玩家直接操作拳手
   - PC 键盘初版：A/D 前后移动，W/S 上下小移；J 刺拳（快/弱/省体力）、K 直拳（均衡）、L 摆拳（慢/重/耗体力）；空格格挡（减伤、不能移动出拳）；体力管理是核心——体力见底则动作变慢、伤害降低
   - 对手 AI：移动、格挡、出拳、战术切换，强度随生涯进度提升
2. **自动观看**（AI 代打，可干预）
   - 双方 AI 对战，支持 2x/4x 加速
   - 保留战术干预（即原指令系统，reframe 为"赛前布置＋中场调整"）：战术倾向切换（强攻/稳守/游走）＋ 即时指令（组合拳爆发/铁壁防守/搂抱）
3. **模拟跳过**（快速推进）
   - 按双方实力一键判定，用于实力悬殊的比赛，显示文字战报摘要

### 手动操作键位方案 v1（2026-10-24）
**设计思路**：2个出拳键 × 方向键 = 多种拳种（类比 Fight Night 右摇杆逻辑）；步伐/闪避/防御是重点，针对 Love Upper 移动差的弱点加强

**移动/步伐**：
- A/D：前后滑步；W/S：上下移动
- 双击 A/D：快速垫步突进/后撤（耗少量体力）
- 距离感：显示双方距离状态（远/中/近），不同距离可用拳种不同

**出拳**：
- J（前手）：无方向=刺拳（快/弱/省体力）；上+J=左上勾；下+J=左击腹（削体力）；前+J=左摆拳
- K（后手）：无方向=直拳（均衡）；上+K=右上勾；下+K=右击腹；前+K=右摆拳
- 每种拳四参数：伤害、速度、攻击距离、体力消耗

**防御/闪避**：
- 空格按住=格挡抱架：减伤70%，不能移动/出拳，成功格挡耗少量体力
- Shift+方向=闪避动作（下潜/侧闪/后仰）：短无敌帧，耗体力15，冷却1.5秒

**界面**：开战前键位说明，H键随时查看，角落常驻迷你键位提示
**触屏版（2026-10-24 补充，用户只有安卓手机）**：
- 自动检测触屏设备，虚拟按键与键盘两套并存
- 左侧虚拟摇杆：8方向移动，方向同时作为出拳修正（上=上勾/下=击腹/朝对手=摆拳/回中=刺拳直拳）
- 右侧按钮：前手拳、后手拳（拳种由摇杆方向决定）、格挡（按住）、闪避（点按+摇杆方向）、垫步
- 横屏布局，按钮够大；键位说明出触屏版
**备注**：操作手感在原型试玩后继续优化

### 模式选用建议
- 头衔战/宿敌战 → 手动操作
- 普通排名赛 → 自动观看
- 新人期虐菜局 → 模拟跳过

## 五之二、局内动画实现规划（2026-10-24）

### 总体方案
- **2D 骨骼动画 ＋ 分层实现**（Godot 正式版；网页原型用简易 sprite ＋ 特效 juice 先验证手感）
- **一套通用骨骼，主角与对手共用**；对手靠体型缩放 ＋ 配色 ＋ 拳套区分，不单独做骨骼——solo 开发降成本的关键

### 动画清单（按优先级）
1. **出拳 5 种**（刺/直/摆/上勾/击腹）：每种"预备→出击→收回"三段，这是拳击感的核心
2. **受击反应**：轻/重两档（头后仰、身体踉跄）
3. **移动**：滑步（step-drag）不是走路，抱架常态小碎步
4. **待机**：抱架 ＋ 呼吸起伏 ＋ 轻微垫步，站着不能像木头
5. 格挡/闪避/倒地/起身/KO/胜利庆祝

### 拳击专项要点
- **距离感**：远/中/近三种站位视觉可辨（原型已有距离状态，正式版用动画强化）
- **动画 × 数值联动**：出拳速度属性 → 动画播放速度；熟练度 → 残影/拖尾，S 级看着就比 F 级利落
- **镜头语言**：重击时轻微 punch-in 推近；KO 时慢动作 ＋ 特写——便宜但效果极好

### 打击感（从原型继承，全部保留）
- 顿帧、震屏、受击闪白、击退、粒子、伤害飘字、合成音效、KO 慢动作＋闪光

### 技术选型
- Godot AnimationTree 做状态机；或 Spine（有 Godot 插件），看顺手程度选

## 五之一、战术干预系统（用于自动观看模式；原"战斗指令系统"）

### 基本框架
- 比赛：3 回合 × 2 分钟（原型参数，可调），回合间 30 秒休息
- 双方 AI 自动攻防，玩家扮演场边教练，只下指令不直接操作
- 指令分三类：战术倾向 / 即时指令 / 回合间调整

### 战术倾向（同时只能生效一种，可随时切换）
- **强攻压制**：出拳频率+、伤害+；代价：体力消耗大、闪避下降
- **稳守反击**：闪避/格挡+、反击伤害+；代价：出拳频率低
- **游走打点**：体力消耗少、点数判定优势；代价：终结能力弱
- **针对弱点**：对弱点部位伤害大幅+；前提：需先侦察出对手弱点

### 即时指令（冷却制，关键时刻用）
- **组合拳爆发**：10 秒出拳速度+伤害提升；冷却 45 秒；时机：对手体力不支/被摇晃时
- **铁壁防守**：10 秒大幅减伤；冷却 60 秒；时机：被压制、回合末保点数
- **搂抱拖时间**：强制缠抱回体力；冷却 30 秒；用多了裁判警告
- **意志爆发**：血量<30%可用，全属性短暂提升；整场限 1 次；翻盘用

### 回合间调整（休息时间专用）
- 处理伤口：回血、清除流血 debuff
- 战术大改：免费切换战术倾向无惩罚
- 场边训话：意志检定成功则下回合小幅全属性提升

### 限制机制
- 原型用冷却制（简单直观）；后期可叠加指挥点数层
- 指令效果与拳手属性挂钩（如组合拳爆发的效果系数受"技术"影响，铁壁防守受"技术/意志"影响）

### 打击感与受击反馈（2026-10-24 补充）
- 顿帧（hit-stop）：命中瞬间冻结 60~100ms，重拳更长
- 屏幕震动：命中小幅、重拳/击倒大幅
- 受击闪烁：被击中者闪白/闪红约 150ms
- 击退位移：向后弹一小段，带回弹缓动
- 打击粒子：命中点爆出星形/汗水粒子
- 伤害飘字：重击大字号/变色
- 音效：Web Audio 合成（轻拳"啪"/重拳"砰"/格挡闷响/回合钟声），无需外部音频
- 受击动作：后仰/踉跄动画；出拳速度线拖影
- KO 特效：慢动作 + 大震屏 + 闪光 + 全屏"KO!"

### 待定
- 具体数值、冷却时长待原型调参
- 对手弱点侦察机制：赛前报告 vs 场上观察

## 七、养成系统：三层属性框架（2026-10-24 细化）

### 第一层：基础身体素质（成长慢，影响全局）
- **力量**：所有拳种伤害基数
- **耐久力**：血量上限、体力上限、抗击打能力、体力恢复速度
- **意志**：逆境加成、意志爆发/训话效果、被重击后恢复

### 第二层：拳击专项能力
- **出拳速度**：出拳动作快慢，影响先手和连击
- **精准度**：命中率，能否打中弱点/空档
- **步伐速度**：移动、距离控制、闪避身法的基础
- **防守技术**：格挡减伤、闪避率、搂抱成功率
- **技术**：综合值，影响组合拳质量、假动作、教练指令效果系数

### 第三层：拳种熟练度（每种拳独立等级 F→S）
| 拳种 | 特点 | 用途 |
| 刺拳 | 快、伤害低、耗体力少 | 控制距离、侦察、打点 |
| 直拳（后手） | 伤害高、速度中 | 主力重击 |
| 摆拳 | 弧线大、易被闪、伤害高 | 近距离重击 |
| 上勾拳 | 破防守、风险高 | 对付高抱架对手 |
| 击腹拳 | 削对手体力 | 中后期拖垮对手 |

- 熟练度影响：该拳种伤害修正、命中修正、体力消耗效率、组合衔接流畅度
- 成长方式：专项训练 ＋ 实战中使用（用得多涨得多）
- AI 会偏好使用高熟练度拳种；教练指令效果与对应熟练度挂钩

### 训练 ↔ 属性映射
- 重沙袋 → 力量 ＋ 重拳类熟练度
- 手靶/空击 → 精准度 ＋ 技术 ＋ 拳种熟练度
- 跳绳 → 步伐速度 ＋ 耐久力
- 长跑 → 耐久力
- 实战陪练 → 意志 ＋ 全熟练度小幅提升
- 力量训练 → 力量（过量影响速度，需取舍）

### 八之一、Phase 3：分阶段目标 ＋ 粉丝 ＋ 赞助（2026-10-24 细化）

## 九之一、装备系统：外观换装 ＋ 深数值（2026-10-24 补充）

### 设计原则：双层结构
- **外观层（看得见）**：版型、颜色、款式 → 需要美术资源，控制数量
- **数值层（看不见）**：材质、内衬、盎司、做工 → 纯数值，可大做特做零美术成本
- 美术只需画 N 种外观，数值组合可程序化生成，性价比最高

### 拳套系统（参考现实设计）
- **版型/系列**（外观＋基础倾向，致敬现实风格，名称虚构）：
  - 守护系（Winning 风）：高保护、低伤手，贵
  - 斗牛系（Cleto Reyes 风）：拳锋硬、伤害高，伤手风险高
  - 经典系（Everlast 风）：均衡便宜，新人首选
- **盎司重量**：8oz（职业赛轻、伤害高）→ 16oz（训练重、保护手）；比赛规则可限定盎司数（参考现实按体重级别规定）
- **固定方式**：系带式（更贴合，比赛用）vs 魔术贴（方便自助穿戴，训练用）
- **材质细分**（纯数值）：
  - 外皮：小牛皮 / 袋鼠皮（轻，+速度）/ 山羊皮 / 人造革（便宜）
  - 内衬缓冲：马毛（传统硬，+伤害，伤手）/ 乳胶泡沫（均衡）/ 凝胶（保护好）
- **收集要素**：拳套图鉴，集齐有成就/加成

### 其他装备
- 衣服（战袍/训练服）：外观换装 ＋ 属性（恢复、体力）
- 护齿：比赛中戴在嘴里，平时不可见 → 主要做数值＋立绘特写表现
- 战靴、绷带等可扩展

### 换装实现（2026-10-24 简化确认）
- **立绘不换装**：人物立绘维持固定 2D 形象，AI 生成，风格统一即可，不做纸娃娃系统
- **仅比赛模型替换装备**：拳套、衣服、鞋子等在比赛模型上做简单 sprite 替换，实现不复杂
- **拳套写实精细**：拳套按写实风格精细绘制（质感、缝线、版型细节），与二次元人物形成"精细道具 ＋ 二次元人物"搭配（类似米哈游式道具精细度）
- 护齿平时不可见，主要做数值

### 装备获取（四途径）
- 商店购买、比赛奖励、成就奖励、游戏内制作

### 制作系统（新增）
- 与材质系统天然契合：拆解淘汰装备 → 获得皮料/内衬材料 → 按配方打造新装备
- 材料来源：拆解旧装备、商店买基础材料、比赛/成就奖励稀有材料
- 形成循环：获取 → 使用 → 淘汰拆解 → 打造更强

## 十一、参考游戏

### マグナムリリィ（漫画，阿部伶，讲谈社）
- 女子拳击题材：失恋少女在游戏中心打拳机发泄，被女拳手发掘带入拳击世界
- **开局参考**：素人开局（街机拳机 → 被发掘 → 进拳馆）非常适合做我们的序章/新手引导
- **双线结构**：热血体育主线 ＋ 百合恋爱副线——与我们的"分阶段目标＋可选恋爱线"设计天然契合
- **美术参考**：画风、人物塑造可作风格参考；**拳套质感写实细腻**，正是我们想要的"拳套写实精细"方向——后续绘制/生成拳套装备图时对标它的质感
- 写实拳击描写可作技术动作参考

### Love * Upper!（PS2，Simple 2000 系列）
- D3 Publisher 的廉价系列作品，女子拳击题材
- **核心参考点**：「美少女 × 写实拳击引擎」的混搭有成功先例——它的拳击物理引擎直接沿用自同系列写实男子拳击游戏《THE Boxing》，再叠加特殊技和服装系统
- **换装收集**：每位拳手多套服装（战斗服/礼服/兔女郎装等），通过锦标赛模式解锁——印证了"换装收集是核心乐趣"
- **特殊技系统**：严肃拳击引擎 ＋ 必杀技/特殊动作，严肃与趣味并存
- **差异**：它是直接操作格斗，我们是玩家手动操作/自动观看/模拟跳过三模式；参考其角色塑造、换装、打击感，操作方式取其精华（见下）

#### 战斗机制参考（2026-10-24 调研，来源：neoseeker 玩家 FAQ v1.4、欧版 Heartbeat Boxing 手册、GameFAQs 评测）
- **双资源条**：橙条=体力 HP（归零直接 KO），绿条=DP（Down Points，归零被击倒）；每回合被击倒 3 次判 TKO；两条在回合间和被击倒时恢复——击倒/读秒机制模板
- **隐藏耐力值**：耐力高时自动回血快、带自动格挡；耐力低时姿态变化、移动变慢、失去自动恢复；可通过搂抱（clinch）和回合间休息恢复——我们的"耐久力"属性可按此实现
- **裁判打分维度**：有效伤害、格挡减伤、闪避、打断对手出招的反击、连招多样性——点数判定的打分可参考
- **操作方案（解决"拳种太多、键不够用"）**：方向＋出拳键改变拳的性质（前＋直拳=突进直拳、前＋勾拳=重勾拳可 stun）；PS2 压感按键=每种拳有"快而弱/慢而重"两版本→映射到触屏就是"点按 vs 长按"
- **反击拳**：闪避后按任意攻击键自动出反击拳，类型取决于闪避方向（后闪→直拳、下闪→上勾、侧闪→勾拳）——降低操作门槛，手机友好
- **策略层**：高位格挡防不住击腹，击腹→直拳是标准破防连招；刺拳伤害低但能打断对手出招、起手组连击（骚扰主力）
- **要避免的缺点**：评测吐槽侧步太好用、失位后只能"先格挡再重新对位"别扭——我们的步伐/距离系统要重点做对；指令可预输入导致动画 laggy——输入队列要设上限/覆盖逻辑

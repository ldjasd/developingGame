# 提案：角色模块化建模

## 一句话提案

角色建模按模块拆分：骨架与动作全员统一，每个角色只需按模块替换自己的部件，就能大批量实装动态角色，而不是每人从头做一遍。

## 背景与来源

- 2026-11-03 用户提出：比赛中人物还是纯贴图，只有主角有动态、对手全是单张站姿图，要求至少做到 2D 建模级动态。
- 2026-11-03 用户定试点：先做主角一人，骨架全员一样。
- 2026-11-04 凌晨主角纸偶试点完成（见 `../CHARACTER_RIG.md` 第六节）：骨架模板 `RIG_TEMPLATE` 与每人标定 `RIG_CHARS` 已分离，动作零改动即可换人；部件全部从定稿姿势图原像素切件，身份零漂移。外推成本约 1~1.7 小时/人（前提是有同朝向抱架＋伸直出拳两帧）。
- 2026-11-04 用户批准：纸偶扩到 8 名重点角色。
- **2026-11-10 用户提出模块化**：角色建模按模块来，每个模块只需按角色替换，即可实现大批量角色实装。

## 方案要点（2026-11-10 版，随推进更新）

模块槽位（统一规格、统一枢轴与轴向定义）：

| 模块 | 内容 | 每角色是否独有 |
|---|---|---|
| 头＋发型 | 脸、发型、发饰 | 独有（身份核心） |
| 躯干服装 | 上衣、腰带、短裤/裙摆图案 | 独有（身份核心） |
| 上臂 | 左右上臂 | 可共用母版，按肤色/袖口换色 |
| 前臂＋拳套 | 伸臂件取伸直形态；拳套按 Winning 版型口径 | 半独有：结构共用母版，拳套配色与腕带按角色换 |
| 大腿 / 小腿＋鞋 | 腿部结构件、拳击靴 | 可共用母版，鞋款配色按角色换 |
| 配饰 | 发带、护具、披风类 | 可选插拔 |

关键规则：

- 骨架、姿势（14）、动作（13）只维护一套，任何角色不单独做动作；左右靠镜像（用户早先定的「一套动作通吃」口径）。
- 身份只由头/发型＋躯干服装＋拳套配色决定；这三类模块必须用角色本人定稿图原像素，防身份漂移。
- 结构模块（手臂/腿）可用主角已验证母版换色，解决对手没有出拳帧的问题——这是批量化的关键：对手不必先补整张出拳立绘。
- 每名角色的交付物 = 一组模块图 ＋ 一份标定数据（`RIG_CHARS.<key>`）；接入保留静态图回退开关。
- 规格先在 8 名重点角色上定死，再往全员 50+ 名铺；规格未定死前不批量生产。

参考机制（2026-11-10 调研已回填，详见 `../research/GITHUB_RESEARCH.md` 第十、十二节）：Spine 的 skins/attachments（skin placeholder 使动画与角色解耦，运行时可组合叠加 base＋hair＋outfit＋accessory）、DragonBones 的两级换件（整套 replaceSkin / 单槽 replaceSlotDisplay）——均为同一骨架多皮肤的成熟做法。Web 阶段不换运行时：继续自研纸偶（零授权、零依赖、身份零漂移），瓶颈在切件/标定工时，不在工具。

调研后的规格升级（v2）：

- 槽位清单细化为：head / hair_front / hair_back / torso / upperarm_near / upperarm_far / forearm_glove_near / forearm_glove_far / thigh_near / thigh_far / shin_shoe_near / shin_shoe_far / accessory，命名 `parts/<char>/<slot>.webp`。
- 模块分工三档：头/脸每人独有（原像素切件）；发型独有形状＋颜色可参数化；躯干服装定 3~4 个版型共用母版、图案配色逐人；四肢/拳套/鞋共用母版换色（肤色 3~4 档、Winning 拳套母版只换配色，装备换拳套走槽位级覆盖）；长发/裙摆做可选模块，不复杂化全员骨架。
- `RIG_CHARS` 升级为「部件装配表」：每个槽位注明来源（独有切件 | 母版 id＋染色参数 | 可选配饰）＋标定数据。
- 落地五步：①先写规格书（槽位/画布/枢轴/z-order/命名/静止重组验收阈值）→②随 8 名批次建母版库 →③装配表改造 →④验收自动化（重组误差、枢轴越界、缺槽回退、四态截图自动生成待目检）→⑤先 8 名验证母版覆盖率（目标 ≥约 70%），成立再流水推其余 40+ 人；体型特殊者只许覆写标定、不许改骨架。
- 诚实边界：被遮挡处的补绘省不掉，排期按「每人仍需少量补绘」估，不按纯换色估。
- 美术冻结约束（2026-11-10 用户定，优先级高于本方案细节）：人物与道具美术资源不变——本方案只做「用原图原像素切件＋装配」的动态化，不重画、不替换角色与道具图；母版换色仅限结构件缺件时的兜底，且必须过身份一致性自审（与本人立绘并排核对），不达标即不用、宁可该角色暂缓扩围。

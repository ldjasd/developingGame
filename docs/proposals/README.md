# 提案文档索引（proposals/）

> 规则（2026-11-10 用户定）：每一个提案写在一个小文档里；同一话题只用同一个文件、持续更新，不新开重复文档。这样随时有参考，也能看到一个想法从提出到落地的全过程。
> 本目录只放「话题/提案」级文档；执行层的四件套（要做的东西 / 实现方法 / 实现后测试 / 改动历史）另在正式版文档集中维护，两边互相链接、不重复抄写。

## 每个提案文档的固定结构

1. **一句话提案**：要解决什么、想达到什么
2. **背景与来源**：谁在什么时候提出、原话大意
3. **方案要点**：具体怎么做（细节随讨论更新）
4. **状态**：提出 / 已批准 / 进行中 / 已落地 / 已否决或被取代（注明被谁取代）
5. **关联文档**：设计、审计、实现记录、测试记录的链接
6. **更新记录**：按日期追加，每次只记「变了什么、为什么」

## 与助手记忆的关系

助手的长期记忆（MEMORY）记的是结论摘要，不是参考文档本身。凡是会影响后续做法的用户提案，先落到这里的提案文档，再把一句话结论同步进记忆——文档为准，记忆为索引。

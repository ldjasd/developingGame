# 提案：人物 3D 建模（正式版方向提前试点）

## 一句话提案
对手 2D 纸偶拼装被用户否决后，人物动态化改走 3D 建模：先在助手 VM 上用 Blender 无头脚本建主角试点模型，验证「建模→绑骨→动画→渲染/Godot」全管线，用户过目粗模后再定铺开节奏。

## 背景来源
- 2026-11-10 用户亲看 G2 对手纸偶实战图后裁定「这完全人都碎了」「表层修不好的得从根上重新做」；助手给出三选项（3D 建模／2D 骨骼建模／整图姿势帧），用户点选「做 3D 建模，往正式版方向走」。
- 与既定正式版方向一致：Phase 8 本就定 Godot 3D、PS2 级（2026-10-24 定案），此前口径是「真 Blender 建模需 PC、留到 Phase 8」；本次变化＝用助手 Linux VM 无头跑 Blender，提前启动试点，不再等 PC。
- 主角三视图/表情/发型/服装细节参考图已于 2026-10-25 备齐（assets/model_reference/），正好作建模参照。

## 方案要点
- 工具链：Blender 4.2.3（~/workspace/.tools/blender/，官网 tarball）；无头环境无 EGL，Workbench 不可用，渲染走 Cycles CPU（48 采样一张约 35 秒）。
- 建模法 v1：实体部件拼装（球/胶体/锥台），关节球交叠——构造上无缺口、无悬浮碎片，先求比例与配色成立；后续迭代向旋盘轮廓躯干、整块马尾、卡通渲染（平色+描边）推进。
- 试点对象：主角（参考最全）。里程碑：粗模（比例/配色/抱架）→ 精修（脸/发型/躯干轮廓/卡通渲染）→ 绑骨＋基础动作（抱架/直拳/受击/倒地）→ 渲染验证 → 用户过目 → 决定铺开与 Godot 接入方式。
- 对手 2D 纸偶部件与母版路线整体作废；对手静态立绘维持现状，直到 3D 铺开或另有新法。

## 状态

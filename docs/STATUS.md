## 已经做出来的

**实时战斗可玩原型**（`godot/scenes/dev/rt_proto.tscn`，用 Godot 打开后 F6）
- 规则：伤害 / 重创 / 击倒读秒 / TKO / 点数沿用已批准口径；新增出拳节拍（前摇 · 停留 · 收招）、对手预兆、受击打断、三向闪避 + 1 秒反击窗口、高 / 低格挡与破防、擂台走位（前后 · 绕圈 · 垫步 · 围绳）、射程、出拳身体前送。
- AI：按防守能力格挡 / 闪避（会闪错）、步法意图（试探 / 压上 / 站住 / 后撤）、风格差异、连打、打完退出来。
- 标定（600 场 AI 对打）：判定 44% / KO 51% / TKO 5%，平均 2.77 回合，势均胜率 45%，+6 属性优势 83%。
- 画面：3D 擂台、VRoid 样例模型（暂代）、主角虚化 + 拳套不透明、脚步动画、四档打击反馈。
- 演出：击倒（后仰 → 跪下 → 读秒 → 起身）、KO（长顿帧 + 慢动作推近 + 白闪爆点 + 仰面倒地 + 转播镜头 + 加速读秒 + K.O. 弹入）。
- 声音：真实录音打击音效、拳击铃；观众按局势变化——平时低声嘈杂，**连续打中**才升温（第 3 拳起、第 4 拳起每 2 拳一声「噢」），被打方越撑不住升得越快，读秒越数越响，KO 后持续吼叫约 22 秒，全程无掌声（用户已认可）。
- 操作：WASD 走位（双击垫步）、J/K/U/I/L 五种拳、空格格挡（+S 低格挡）、Shift + 方向闪避、C 切镜头。

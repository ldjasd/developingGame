# 游戏愿景（一页）

> 状态：**草案，P0 结束时定版**。这一页是所有设计的「宪法」：新想法和它冲突时，要么改想法，要么正式改这一页（写进 `DECISIONS.md`）。

## 一句话
**《心跳在左，拳头在右》**：带一名二次元美少女拳手从街机测力机前的素人，一路打到世界冠军——白天训练养成，比赛日亲手上擂台实时对打。

## 三根支柱
1. **亲手打的拳击**：比赛是实时操作，读招、闪避、反击、击倒读秒，打击感要扎实。
2. **看得见的成长**：训练和装备的变化要在比赛里感受到、在角色身上看得到。
3. **有人情味的生涯**：梢姐、队友、宿敌和对手都有自己的故事；输赢都有情绪落点。

## 目标玩家
- 喜欢二次元角色、也愿意玩一点动作操作的 PC 玩家；
- 一次游玩 30~60 分钟，完整通关 6~10 小时。

## 平台与形态
- Windows 桌面版（Godot 4），键盘 / 手柄；中文；免费、非商用发布（itch.io）。

## 不做（范围外）
- 联机对战；
- 多体重级别、真实拳击组织授权；
- 写实画风；
- 商业化内容（付费、广告）。

## 参考
- Love Upper（PS2）：美少女 × 拳击引擎、共用骨骼动作扩角色、换装收集——只做研究参考，不使用其任何资源。
- Bloom Blow：比赛演出、局间指导、赛前预测、生涯结构——只观察游玩，不提取文件。
- 漫画《マグナムリリィ》：素人开局、画风、拳套质感。

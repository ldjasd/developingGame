# 对手角色池名册（v0.1）

> 制定：2026-10-25 ｜ 系统原则（用户定）：具名角色池制——不按等级创作、不贴固定段位；每名角色有初始实力与成长类型，随游戏推进随机成长/波动，排名与比赛匹配由系统按当前实力自动分配。初始时选一部分人实力高、占高位，保证开局上层有人。
> 规模：对手 50 名（初始排名 1~49 共 49 人＋候补 1 人），玩家初始第 50 名。另有剧情角色 2 名（不入池）。
> 名字全部为占位名，待用户定名后替换。立绘在 `assets/opponents/`，与主角 v8 同画风。

# 生涯与养成设计

> 状态：**部分定稿**（现行系统可玩）；生涯终点、难度梯度、经济为**草案**。
> 现行实现：`godot/scripts/game_state.gd`，数据 `godot/data/`（trainings / stages / roster / sponsors / influence_levels / constants）。

## 1. 现行系统（已实现，保留）

| 系统 | 规则摘要 |
|---|---|
| 时间 | 每天 6 AP；一周 7 天；正式赛只在每周第 7 天，每个比赛日 1 场；约战 2 AP 随时 |
| 训练 | 训练行动 2 AP → 5 个训练点，13 种训练按重 3 / 中 2 / 轻 1 点组合；体力透支每 10 点 → 伤病 +5 |
| 属性 | 力量、耐久、意志、出拳速度、精准度、步伐速度、防守技术、技术 + 5 种拳种熟练度 |
| 心态 | 0~100 五档；≥80 训练 ×1.1，<20 训练 ×0.85、比赛体力消耗 ×1.1；20~39 比赛全属性 ×0.95；胜 +15 / 负 −10 / 被 KO −25；睡觉向 60 回归 |
| 排名 | 50 人具名角色池，每周池内模拟、按实力重排；±5 名匹配 |
| 影响力 | 5 档，按胜场 / 排名实时计算、可升可降；出场费 +0/10/20/35/50% |
| 阶段 | 6 阶段（初出茅庐 → 传奇之路），带奖金与称号 |
| 赞助 | 4 档，签约金 + 周薪 |
| 卫冕 | 登顶后第 2~6 名发起挑战，每周至多 1 场 |

## 2. 要加 / 要改

### 2.1 生涯终点（待拍板 #3）
- **主线**：约 40~60 周。终点事件 = 国内冠军后的「世界挑战赛」（3 场连战，最后一场是最终对手）。
- **结局**：3 种——世界冠军 / 惜败但被认可 / 退役（累计伤病过高）。看成绩 + 关系值决定结局 CG 和尾声文字。
- **通关后**：自由模式，继续卫冕、收集服装、刷图鉴。
- **退役压力**：每次被 KO 累计「伤痕值」，超过阈值后耐久成长减半；超过上限强制进入退役结局。让生涯有长度和风险。

### 2.2 难度梯度
- 比赛屏的 3 个候选固定为「稳（胜算 ≥ 65%）/ 五五（40~60%）/ 冒险（≤ 35%）」，冒险赢了奖金 ×2、影响力额外 +。
- 第 1~4 周为新人期：对手属性有下限保护，保证至少一个候选胜算 ≥ 60%（现在是两个 5~8%）。
- 连输同一人 2 次 → 触发宿敌剧情 + 免费侦察一条对手习惯。

### 2.3 训练互动
- 手靶（节奏）、速度球（连按）、闪躲球（反应）3 种做成 15 秒小游戏；成绩 S/A/B/C 对应收益 ×1.3/1.15/1.0/0.85；可选「自动」（固定按 B 算）。
- 其余训练保持选择式，但要有动画（中枢小窗播放对应动作）。

### 2.4 经济
- 目标：第 20 周存款 ≤ ¥5,000（会花钱的玩家）。
- 新出口：服装 / 外观（`equipment.md`）、雇佣陪练（一周训练效率 +10%，¥2,000/周）、医疗（伤病 −20，¥1,500）、集训营（每 10 周一次，3 天特训，¥8,000）。
- 复查打工收入和输球奖金（输了还拿 30% 是否过高）。

### 2.5 养成可视化
- 熟练度到 B / A / S：对应拳种出拳更快、带残影。
- 阶段推进时中枢立绘换装（训练服 → 比赛服 → 冠军夹克）。

## 3. 平衡目标（试玩机器人验证，见 `../process/TESTING.md`）

| 指标 | 目标 |
|---|---|
| 第 1 周最佳候选胜算 | ≥ 60% |
| normal 策略 20 周正式赛胜率 | 45~60% |
| 同一对手连输 ≥ 3 次的次数（20 周） | ≤ 1 |
| 主线通关周数（normal 策略） | 40~60 |
| 第 20 周存款 | ≤ ¥5,000 |

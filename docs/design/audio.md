# 音频设计

> 状态：音效**定稿**（用户 2026-11-21 认可）；BGM **来源待确认**（发布阻塞）。
> 来源与授权：`godot/assets/audio/CREDITS.md`。生成 / 修音脚本：`godot/tools/`（design_punches.py、make_bells.py、make_air_crowd.py 等）。

## 1. 原则（用户反馈固化）
- 只用真实录音，**不变调**（变调听起来像加了滤镜）。
- 打人的声音 ≠ 打沙袋的声音：命中用「打在人身上」的录音为主体。
- 挥空用衣物挥动声，不用竹竿 / 金属类。
- 只用 CC0 / CC BY 素材，来源和改动写进 CREDITS；不用影视 / 其他游戏的音频。

## 2. 现有音效
命中（轻 / 重 / 击腹）、格挡、倒地、挥空、观众欢呼、开场铃、终场铃——见 CREDITS 表。

## 3. 要补
| 项 | 用途 |
|---|---|
| 读秒报数 | 裁判数「1、2、3……」（可录音或用钟声 + 字幕代替） |
| UI 音 | 按钮点击、确认、取消、购买、升级、成就 |
| 训练音 | 跳绳、沙袋、速度球 |
| 局间 | 教练喊话氛围、喘气 |
| 必杀 | 特写出现时的冲击音 |
| 低体力 | 喘气声（循环） |

- 设置里三条音量：主音量 / BGM / 音效（Godot 音频总线 Master / Music / SFX）。

# UI / UX 设计规范

> 状态：**草案**。素材：`godot/assets/ui/`（muse 素材套，说明见 `godot/assets/ui/UI_KIT_NOTES.md`）。
> 现行实现：`godot/scripts/main.gd` `_build_theme()`；所有界面目前写在 `main.gd` 一个文件里。

## 1. 风格

| 项 | 规定 |
|---|---|
| 主色 | 粉 #f27bb5、紫 #7b4bb5、深紫 #4a2a7a；金色只做点缀 |
| 底色 | 深紫半透明面板（panel.png），不用纯黑、不用纯白 |
| 字体 | 正文：思源黑体（SIL OFL，可商用）；标题：一款粗体标题字（待选，必须可商用） |
| 字号 | 1080p 下正文 18px、小字 14px、标题 28px；最小不低于 14px |
| 按钮 | muse 九宫格贴图，最小 84×40；主操作按钮更大、带图标 |
| 图标 | 128px 徽章风格（属性、拳种已有）；状态值（心态 / 影响力 / 疲劳 / 伤病）待补 |
| 动效 | 界面切换 0.2s 淡入；按钮悬停 0.1s 放大 1.03；数值变化时数字滚动 |

## 2. 界面清单

| 界面 | 现状 | 要做 |
|---|---|---|
| 标题 | 有 | 加「设置」「致谢」「退出」 |
| 序章 | 有（纯文字） | 加立绘 / CG |
| 中枢 | 有（刚换皮） | 日志收成通知；行动按钮做成图标卡片；顶栏改成图标 + 数值 |
| 训练计划 | 有 | 训练项目做成卡片（图 + 收益），预览改条形图 |
| 商店 / 工坊 | 有 | 按 `equipment.md` 重做；商品要有图 |
| 比赛选择 | 有（胜算条） | 候选做成「稳 / 五五 / 冒险」三张对手卡 |
| 赛前 VS | 无 | 左右半身立绘 + 名字 + 数据对比 + 赛前台词 |
| 战斗 HUD | 有（默认样式） | 头像 + 分段体力 + 回合钟 + 战术名 + 必杀能量 |
| 回合间指导 | 无（只有战术按钮） | `battle.md` §8 |
| 赛后结算 | 有（文字） | 胜负横幅 + 影响 + 每回合打分 |
| 剧情弹窗 | 有（立绘 + 文字） | 加 CG、选项样式统一 |
| 状态 / 背包 / 图鉴 / 成就 / 排名 | 有（简陋） | 统一成标签页式「档案」界面 |
| 设置 | **无** | 音量（主 / BGM / 音效）、全屏 / 窗口、分辨率、键位（可改）、伤害数字开关、读招提示开关、文字速度 |
| 暂停 | **无** | 继续 / 设置 / 认输 / 回标题 |
| 存读档 | 逻辑有，界面简陋 | 3 槽卡片（周数、排名、截图） |
| 致谢 | **无** | 读 `godot/assets/audio/CREDITS.md` 等，滚动显示 |
| 结局 | **无** | CG + 尾声文字 + 生涯数据 |

## 3. 交互规范

- 消耗 AP 或推进时间的行动：先确认（已有，保留）。
- 所有界面都能用键盘 / 手柄操作（焦点高亮、Esc 返回）。
- 鼠标悬停显示说明（替代现在的大段文字）。
- 任何时候 Esc 都能回到上一层，不会卡死。

## 4. 工程要求

- 把 `main.gd` 里的每个界面拆成独立场景（`scenes/ui/hub.tscn` 等），用一个全局 Theme 资源（`assets/ui/theme.tres`）代替代码里拼主题。
- 分辨率：在 1280×800、1920×1080、2560×1440、21:9 下截图自检，不糊不裁。

## 5. 验收标准
- 每个界面截图对照本规范逐项打勾（`../process/TESTING.md` 的 UI 检查表）；
- 新手（没玩过的人）不看说明能在 2 分钟内完成「训练一次 → 睡觉 → 报名比赛」。

## 0. 测量精度说明（先读）

- 截图工具连拍一张大约要 **1.1 秒真实时间**，所以**亚秒级的出拳帧数（起手到命中多少毫秒）测不出来**。下文凡是「≥」「约」的数，都是从「这个姿势在多少张连拍里出现」统计反推的，不是逐帧量出来的。
- 比赛时钟是压缩的：×1 时第 1 回合 1:22→0:53（游戏内 29 秒）只用了 12 张连拍，约 13 秒真实时间。**游戏内 2:00 一回合 ≈ 真实 50~55 秒（×1）**，×1.5 约 35 秒。局间休息的 0:30 倒计时基本是真实时间。

## 2. 出拳演出

| 项 | 观察 / 估算 | 截图 |
|---|---|---|
| 关键姿势数 | 一记拳**只有 1 张「伸出 / 命中」画**，加上回到架势；没看到明显的蓄力帧。勾拳多一张「收招横臂」 | [09][14] |

| 连击 | 一次进攻是 2~3 拳的组合，**攻击方头顶飘一块半透明深底白字标签写连招名**，例如「ダブルジャブ」「ストレート→ボディーフック」「断千拳→勾拳→直拳」，持续约 1~2 秒 | [05][13] |

| 设置 | 「招牌技特写」可选 每次 / 首次 / OFF；「连击提示」开关；比赛速度 ×1 / ×1.5 / ×2；「汗水与流血效果」轻微 / 标准 / 强烈 | [22] |

## 4. 倒地 / 读秒 / KO

**击倒过程**（第 2 场第 2 回合，每张截图间隔约 1.1 秒）：
`[24] 踉跄弓背 → [25] 膝软前倾 → [26] 跪地、手撑地 → [27] 俯卧（读秒出现「1」）→ [28] 撑起成跪趴（「2」）→ [29] 一直保持跪趴到「5」` → 回合时间到，局间救回（读秒期间**回合时钟继续走**，所以会出现「被铃声救下」）。
- 倒下：约 3 秒真实时间、4 个姿势，**是一步步往下崩的，不是一下就躺平**。
- 进攻方在对手倒地后自动**走回中立角**，守着架势。
- **读秒数字**：画面中上方一个大号白色斜体衬线数字，粉色描边，带樱花瓣装饰；每个数字单独弹出，**大约 1.0 秒一个**（×1 时连拍 2.1 秒能跨过 2 个数）。
- 局间：如果刚被击倒，局间指导面板会多出一个红色的紧急选项（第 9 格）[30]。

**KO**（第 2 场第 3 回合）：
`俯卧 → 仰躺大字 [31] → 读秒 3…9 [32] → 「10」[33]（顶部比赛状态栏同时变成 RESULT「LOSE」）→ 约 2 秒后「10」换成大号「KO」标志 [34][35]`
- KO 标志：白色斜体大字 + 粉色描边 + 樱花枝 + **黑色墨溅 / 碎裂纹**，宽度约占画面 1/3。
- **没有慢动作、没有镜头推近**（KO 那一击在连拍里没有被拉长）。演出靠的是：读秒数字 + KO 标志 + 胜者在中立角站着 + 底部解说。
- 之后点「比赛结果」，先进**全屏败北事件 CG**（败方在角柱旁瘫坐，脸上有伤，配独白），带 3 个教练回应选项 [37]，然后才是结算页 [38]。

**判定**：第 4 回合结束顶部显示「DECISION END」→ 中央半透明黑带逐行宣读「Judge A 39-38…根据 3-0 的判定，胜者是蓝角」[18] → 顶部变成「RESULT LOSE」→ 胜者举拳、败者低头 [19]。

## 5. 镜头

- **全程单一固定机位**：侧视全景，能看到整个擂台和观众。不推近、不切镜头、不分屏、不放慢（以 1.1 秒采样看）。
- 只有两种「镜头感」：①必杀特写（压暗 + 横条胸像，是 UI 叠层，不是真镜头）；②回合开始的「ROUND 1」大字横幅 [04]。
- 开场「VS 入场演出」：左右两张大半身立绘 + 大字名字 + 中间 TALE OF THE TAPE（排名 / 战绩 / KO 率 / 年龄 / 国籍 / 风格）+ 两人赛前台词，点击继续 [03][23]。

## 8. 对我们 Godot 版的具体建议

对照现状（交换式回合、整帧角色、Love Upper ×1.25 的时间轴、顿帧 0.035~0.11s、震屏 2~11px、重击推近 1.06~1.1、KO 慢动作 0.28×0.7s）。

### 8.1 方向确认
- **整帧角色这条路是对的**：Bloom Blow 全程整帧精灵，零撕裂。别回到切件骨骼。它的观感靠「**画够姿势**」，不靠补间。
- 主角「换图 + 位移」不顺，根本原因是**姿势不够**（只有 10 张单姿势），不是程序问题。按 8.4 的清单把美术补齐，比在代码里调缓动更有效。

### 8.2 时间与打击感（逐条改成多少）

| 现状 | 建议 | 理由 |
|---|---|---|
| 刺拳全长 0.28s，到顶 0.06s | 到顶保持 0.06s，**伸直姿势额外停留 0.12s**（全长约 0.34s） | BB 的命中姿势停留明显，整帧画需要被「看见」；我们是交互式，不能停得像它那么久（≥0.3s） |
| 直拳 0.125 / 0.6 | 不动；命中后停留 0.15s 包含在全长里 | 已经够定格 |
| 勾拳 0.27 / 0.85 | 不动；**加一张「收招横臂」画**，放在收招段 0.2s | BB 勾拳最有辨识度的就是收招横臂 [14] |
| 击腹 0.35 / 1.06 | 不动；受击方用「前屈弓腰」画 [42] | — |
| 顿帧 0.035~0.11s | 轻拳 0.03 / 中拳 0.06 / 重拳 0.09 / 必杀 0.14 | 交互式需要顿帧，但 BB 证明了**小特效 + 姿势定格**本身就能撑住，不用再加长 |
| 震屏 2~11px | **普通拳 0~3px，重拳 5px，只有击倒 / 必杀用到 8~11px** | BB 普通命中完全不震，满屏一直震会削弱「大事件」的分量 |
| 命中星形闪光 + 圆环 + 火花 | 普通拳只留**小星爆（≈头部大小）**；圆环 + 火花只给重拳 / 反击 | BB 的命中特效很克制，信息靠姿势和文字传达 |
| 伤害数字 | **改成默认隐藏**（设置里能开），用分段体力条 / 花形图标替代 | BB 没有伤害数字，体力用 8 颗图标表现，更符合「拳击」 |
| 重击推近 1.06~1.1 | 只在**击倒那一拳**和**必杀**时推近；普通重拳不推 | BB 全程固定机位 |
| KO 慢动作 0.28× 0.7s | 保留（我们是交互式，玩家需要这个回报），但**把时长缩到 0.5s**，紧接着进入「崩倒序列 + 读秒」 | BB 的 KO 演出靠的是读秒和标志，慢动作不是核心 |

### 8.3 要新增的演出（按优先级）

1. **击倒 → 读秒 → 起身 / KO 流程**（解决「几乎都打到 KO」）：
   - 体力归零时不直接 KO，先「击倒」：崩倒序列（踉跄 0.4s → 跪地 0.4s → 倒地），进攻方自动走回中立角。
   - 读秒：**每 1.0 秒一个数字**，画面中上方的大号装饰数字（我们可以换成自己的心形 / 拳套主题），每个数字 0.15s 缩放弹入。
   - 起身判定放在 4~9 之间：成功就播「跪趴 → 起身 → 架势」；数到 10 就 KO。
   - 读秒期间**回合时钟照走**，允许「被铃声救下」。
   - 建议规则：同一回合被击倒 3 次才算 TKO，体力有余量，让判定胜负成为常态（BB 第 1 场就是 39-38 ×3 的判定）。
2. **KO 标志**：「KO」大字 + 本作主题装饰（墨溅 / 碎裂纹）出现在「10」之后约 1.5s；顶部状态栏同时切到 RESULT。
3. **连招名标签**：攻击方头顶飘一块半透明深底白字（「刺拳 → 直拳」），显示 1.2s。成本低，可读性提升很大。
4. **必杀 / 招牌技特写**：压暗 50% + 横条（高度为画面 1/3）+ 胸像 + 台词 + 招式名，**总长 1.0s**（入 0.15 / 停 0.7 / 出 0.15），结束后马上接那一拳的命中。设置里给「每次 / 首次 / 关」。
5. **擂台地面残留汗 / 血颗粒**：命中时喷 3~6 个小点，落地后留在地面（上限约 200 个，跨回合保留），设置里给「轻微 / 标准 / 强烈」。
6. **LIVE 解说栏 + 角落喊话气泡**：左下 3 行滚动，事件驱动（落空、连中、击倒）。

### 8.4 给美术的关键姿势清单（每名角色）

**必需（MVP 12 张，主角优先）**：
1. 架势 A　2. 架势 B（呼吸 / 脚步交替）　3. 刺拳伸直　4. 后手直拳伸直　5. 勾拳命中　6. 勾拳收招（横臂）　7. 上勾拳命中　8. 击腹（低位）　9. 格挡（闭眼缩拳）　10. 打脸受击（后仰、闭眼、甩发）　11. 打腹受击（前屈）　12. 倒地（俯卧）

**进阶（+8 张，做完击倒流程就需要）**：
13. 下潜闪避　14. 后仰闪避　15. 踉跄　16. 单膝跪地　17. 跪趴（撑地）　18. 仰躺 KO　19. 胜利举拳　20. 败北低头

规格建议：全部画在**同一张画布尺寸**上（例如 512×768 透明 PNG），**脚底基线和身体中心固定在同一像素位置**，这样换图时不会跳。每张画完整全身，不要拆件。头部高度保持一致，以免切换时头部抖动。

**事件 CG（另算）**：每名主要对手 1 张「赛后」插画（胜 / 负各 1 张更好），配 2~3 个回应选项。这是 BB 情绪落点最强的一环 [37]。

### 8.5 UI 参考（中枢 UI 从调试风格升级）

- 局间面板：4×2 指令格 + 3 张效果卡 + 右侧选手立绘卡 + 30 秒倒计时 [10]。我们的「战术切换」可以直接套这个格局。
- 赛前：**胜负预测 5 段比例条**（KO 胜 / 判定胜 / 平 / 判定负 / KO 负）[02]，信息量大，做起来便宜。
- 赛后：上方横幅（胜者彩色、败者去饱和 + 双方台词 + 「3R 2:00 KO」），下方左边是影响、右边是每回合打分表 [20][21]。
- 战斗 HUD：头像 + 分段体力（替代数字）+ 当前战术名 + 按键提示 [13]。

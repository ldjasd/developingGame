## 对我们有用的结论
1. **轻拳与重拳差距在收招，不在前摇**：刺拳 3 帧到位、直拳 6 帧，重拳也只有 13~16 帧；拉开差距的是收招（6 → 17 → 30 → 48 帧）。打空重拳要被惩罚。
2. **上下半身分层**：#21 起大量片段只动下半身（手臂保持默认），说明步伐和出拳是两层动画叠加，可以一边移动一边出拳。Godot 用 AnimationTree 的分层混合可以做到。
3. **每个大招都带全身位移**：重拳 / 闪避反击类动作头部位移 40~50（身高约 166），比轻拳（9~15）大好几倍；重量感来自整个身体压上去，而不只是手臂伸出。
4. **角色量**：11 人 × 3~4 套服装 × 2 配色，共用一套骨骼和动作；靠换模型、贴图来扩充角色，不用每人重做动作。

### 补充结论
5. **受击分 5 档时长**：最轻 6 帧（0.1 秒）就恢复，重一档 9/12/19/25 帧，再往上是 60 帧踉跄、100 帧以上弯腰眩晕。打击感很大一部分来自「受击方的反应时长和打击力度对应」。
6. **倒地读秒有完整的成功/失败分支**：每种倒地姿势都有「起身成功」和「起身失败又倒回去」两条动画，读秒的悬念靠这个演出撑起来。
7. **回合间有坐凳休息动画**，体力低时有专门的弯腰喘息待机——状态直接体现在姿态上，不只是血条。

### 左右与方向细分（2026-11-21 第二轮）
- 坐标判定：角色面朝 −Z；骨骼链 31~39 是前手 / 前脚（左），22~30 是后手（右）= 正架（左脚在前）。刺拳用左手、直拳用右手，与正架一致；在 Godot 背面视角下，向左倾的受击动作也确实往角色左侧倒。
- 出拳按数据分类：拳头在到顶前横向摆幅大 → 勾拳，竖直抬升大 → 上勾，否则 → 直线；到顶时拳头低于胸口 → 击腹。前缀保留动作组（踏步 / 低姿态 / 前压 / 冲步 / 下潜）。
- 受击按头部被打的方向：后仰 = 被打脸，前屈 = 被打腹部，左右 = 侧面受击；强度按时长（轻 ≤9 帧 / 中 ≤19 / 重 ≤40 / 很重）。
- 倒地按最终姿态：仰面 / 俯卧 / 跪坐 / 站起。
- 出拳表里的「收招帧」现在是从到顶到结束的总帧数（之前只算了离开伸展区之后），所以刺拳 9、直拳 22。

细分后的名字写在 `motion/clip_labels.csv`，glTF 动画名同步更新。

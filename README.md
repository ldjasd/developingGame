# 拳击养成游戏（原型 Phase 1）

二次元美少女主角的拳击养成经营游戏：从默默无闻的新人开始，通过每日训练、打工、外出，赚钱买装备、提升属性，一路打到世界冠军。

## 试玩

直接用浏览器打开 `index.html` 即可游玩（手机/PC 均可，手机横屏体验更佳）。

也可以开启 GitHub Pages 在线玩：仓库 Settings → Pages → Branch 选 `main` → 保存，然后访问 `https://<你的用户名>.github.io/developingGame/`。

## 玩法

- **每日循环**：每天 6 点行动点，分配给训练、打工、外出、休息；行动前有确认框，确认后才结算
- **训练计划**：点"训练"进入计划界面，有 5 个训练点数，11 种训练按强度（重 3 点 / 中 2 点 / 轻 1 点）自由组合
- **属性**：力量、耐久、意志、出拳速度、精准度、步伐速度、防守技术、技术 ＋ 5 种拳法熟练度（F→S）
- **心态系统**：0~100 五档（高昂/良好/平稳/紧张/疲劳），影响训练效率和比赛发挥
- **外出**：体育用品店（买拳套/护具/消耗品）、散心回心态
- **背包/状态**：查看立绘、属性、切换装备、使用道具
- **比赛**（每周第 7 天，报名免费）：三种模式
  - 手动操作：亲自上场，PC 键盘（WASD 移动，J/K+方向出拳，空格格挡，Shift 闪避）/ 手机触屏（虚拟摇杆+按钮）
  - 自动观看：AI 代打，可调战术、加速
  - 模拟跳过：一键出结果
- **打击感**：顿帧、震屏、伤害飘字、KO 慢动作、合成音效
